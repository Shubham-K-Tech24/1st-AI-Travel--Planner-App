# Romancham Travel Assist

Romancham Travel Assist is a Streamlit app that uses Google's Gemini API to generate a personalized travel itinerary. Choose a destination, trip length, budget category, and travel group to get suggestions for attractions, food, accommodation, transportation, local experiences, and estimated costs in Indian rupees.

## Requirements

- Python 3.9 or later
- A Gemini API key with access to the model configured in `main.py`

## Setup

1. Open a terminal in the project directory.
2. (Optional) Create and activate a virtual environment.
3. Install the dependencies:

   ```bash
   python -m pip install streamlit google-genai python-dotenv
   ```

4. Create a `.env` file in the project directory and add your API key:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   ```

   Keep this key private. The `.env` file is excluded from Git.

## Run

Start the app from the project directory:

```bash
streamlit run main.py
```

Streamlit opens the app in your browser. Enter a destination, select a trip duration from 1 to 30 days, choose a budget and traveling group, then select **Plan Your Trip**.

## Notes

- The itinerary is generated by an AI model and may contain errors. Verify opening hours, prices, transport details, and other time-sensitive information with reliable sources before traveling.
- Estimated trip costs are suggestions, not quotes or guaranteed prices.
- The app sends the trip details to the Gemini API to generate the itinerary.
